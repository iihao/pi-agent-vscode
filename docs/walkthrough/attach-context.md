## Give pi the right context

Pi only sees what reaches it. You can:

- Type `@` in the composer to mention a file, or drop files onto it.
- Attach the current file or selection with the 📎 button (or right-click →
  **Pi: Attach Selection to Chat**). Attachments are sent as `@path:12-30`
  references, so pi reads the current file itself.
- Paste a screenshot to send it to a vision model.
- Turn on **automatic context** in settings to attach the open file, selection,
  diagnostics, and Git state to every message:

[Open Settings](command:workbench.action.openSettings?%22pi-agent.context%22)
