## Open the chat

Open the Pi panel from the Activity Bar, or use any of these:

[Open Pi Chat](command:pi-agent.openChat) · [New Chat](command:pi-agent.newChat) · [Open in Editor Tab](command:pi-agent.openInEditor)

Then describe a task in the composer. While pi is working you can keep typing —
**Enter** queues a follow-up, **Ctrl/⌘+Enter** steers the running turn. Start a
message with `!` to run a shell command, or `/` to use a pi command or skill.
